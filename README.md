# Bluewire Mod

Turn your redstone dust into customizable colors!

[中文](./README_CN.md)

## Features

- **Custom Colors**: Set high-power and low-power colors for redstone wire
- **Hex Code Input**: Enter 6-digit hex color codes directly (e.g. `#0080FF`)
- **Color Picker**: Built-in HSV gradient grid for visual color selection
- **Semi-transparent Config Screen**: See the game behind the settings panel
- **Save Without Closing**: Apply changes and keep tweaking without reopening

## Configuration

Open via Mod Menu → Bluewire settings, or use the `/bluewire` command (if available).

- **High Power Color** (signal 15) — default bright blue `#0080FF`
- **Low Power Color** (signal 0) — default dark blue `#00004D`
- **Reverse Direction** — swap high/low color assignment
