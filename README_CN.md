# Bluewire 模组

让红石粉末变成你想要的任何颜色！

[English](./README.md)

## 功能

- **自定义颜色**：分别设置高功率和低功率时的红石线颜色
- **十六进制输入**：直接输入 6 位颜色代码（如 `#0080FF`）
- **色域选色器**：内置 HSV 色调/亮度渐变网格，点击即可选色
- **半透明配置屏**：设置界面半透明，随时查看游戏内效果
- **保存不退出**：点击保存应用更改后继续调整，无需反复打开

## 配置

通过 Mod Menu → Bluewire 设置打开，或使用 `/bluewire` 命令（如已实现）。

- **高功率颜色**（信号强度 15）— 默认亮蓝 `#0080FF`
- **低功率颜色**（信号强度 0）— 默认暗蓝 `#00004D`
- **反转方向** — 交换高低功率的颜色分配
